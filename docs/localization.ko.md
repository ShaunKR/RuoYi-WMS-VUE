# 한국어 화면 적용

## 적용 범위

- 로그인·회원가입·오류 화면과 공통 메뉴, 탭, 검색, 업로드 안내
- 창고·거래처·브랜드·상품·규격 관리
- 입고·출고·재고 이동·실사 전표와 재고 통계·이력
- 시스템 관리 및 모니터링 화면의 고정 문구
- 대시보드의 고정 표시 문구와 인쇄 양식의 필드명
- Element Plus 한국어 로케일, 문서 언어 `ko`, 한국어 글꼴

## 서버에서 내려오는 표시 문구

`src/locales/ko-labels.json`에 알려진 중국어 표시명과 한국어 표시명을 관리한다.
`koreanLabel()`은 정확히 일치하는 표시명만 번역하며, 모르는 문자열은 그대로 반환한다.

- 동적 메뉴: `src/store/modules/permission.js`에서 `route.meta.title`만 변환한다.
- 상태·유형: `src/utils/dict.js`에서 `dictLabel`을 변환한다. `dictValue`는 유지한다.
- 서버 언어: 요청 헤더 `Content-Language: ko_KR`를 전송한다.

사용자가 등록한 상품명·창고명·거래처명과 원본 DB 데이터를 일괄 번역하거나 덮어쓰지 않는다.
금액의 `元`은 **위안**으로 표시한다. 통화 환산을 수행한 것은 아니다.

백엔드의 같은 이름 브랜치 `ShaunKR/wms-ruoyi:portfolio/korean-ui`를 함께 사용해야
한국어 로그인 검증 메시지와 WMS 오류 메시지가 표시된다.
원본 소개 페이지의 개발 연혁은 원본 개발팀의 소개임을 표시한다.

## 확인 범위

- 프런트엔드 프로덕션 빌드
- 로그인 화면의 제목·입력란·버튼·필수 입력 안내를 실제 브라우저에서 확인
- 개발 프록시를 통한 백엔드 인증 이미지 API 응답 확인
- 알려진 메뉴·상태 표시명 번역 및 미등록 문자열·숫자 코드 유지 확인
- 백엔드 로그인 검증 오류가 `ko_KR` 요청에 한국어로 반환됨을 확인

로그인 후 모든 화면에 대한 수동 E2E 검증을 수행한 것은 아니다.
원본 데이터의 중국어 이름, 원본 주석·참고 문서, 외부 라이브러리 자체 편집 화면과
이미지 속 글자는 위 고정 UI 문구 번역 범위에 포함되지 않는다.
